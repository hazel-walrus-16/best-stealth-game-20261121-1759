Shadow Vault is a top-down stealth game: slip past patrolling guards and their vision cones, hide in bushes, duck behind crates, toss coins to lure guards away, grab data shards, and reach the green exit unseen across three hand-built levels.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD or arrow keys, hold Shift to sneak, click to throw a coin.
